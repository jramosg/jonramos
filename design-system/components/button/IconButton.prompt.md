Icon-only square button for toolbars, theme toggles and social links. Always pass `label`.

```jsx
<IconButton label="GitHub" href="https://github.com/jramosg">
  <svg viewBox="0 0 24 24">…</svg>
</IconButton>
<IconButton label="Search" variant="solid" size="lg">…</IconButton>
```

Variants: `ghost` (hairline) · `solid` (raised surface). Sizes: `sm` · `md` · `lg`.
