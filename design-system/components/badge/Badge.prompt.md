Status pill — "Available", "Present", "Open source". Carries an optional pulsing dot for live status.

```jsx
<Badge tone="teal" dot pulse>Available for work</Badge>
<Badge tone="shell">Open source</Badge>
<Badge tone="neutral">Draft</Badge>
```

Tones: `moss` · `blush` · `clay` · `neutral`. Use `pulse` sparingly — only for genuinely live status.
